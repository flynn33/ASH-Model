# ASH-Network paper development notes

## Recommended title

ASH-Network: A Recursive Associative Architecture for Subconscious Memory in AI Agents

## Alternative titles

- From ASH to ASH-Network: Recursive Memory and Experience-Triggered Recollection for AI Agents
- ASH-Network: Source-Backed Associative Memory with Pre-Dispatch Recollection for Artificial Intelligence Agents
- Memory Before the Question: Recursive ASH Addressing and Background Recollection for AI Agents

## Central thesis

ASH-Network turns ASH's finite local alphabet and recursive organization into a persistent associative memory whose sourced experiences can enter an agent's working context at a decision point without an explicit memory query.

“Subconscious” describes the initiation of recollection, not subjective experience. The recollection itself is explicit and inspectable. Neither the finite local alphabet nor the unbounded mathematical path grammar alone establishes intelligence.

## Manuscript structure

1. Introduction: why retaining a memory is different from using it at the right time.
2. ASH foundation: local geometry, parity/code distinctions, recursive addressing, and stable identities.
3. Persistent associations: evidence support, correction, and automatic capture.
4. Memory pressure: observable event sequences, recognition, delivery, and agent choice.
5. Evaluation design: separate retrieval, geometry, sequence, and agent experiments.
6. Results: positive outcomes, controls, and dispatch/narrative discrepancies.
7. Related work: persistent, linked, proactive, and prospective memory.
8. Limitations: attribution, generalization, provenance, security, and runtime costs.
9. Next experiment: matched storage and intervention-policy ablations on new tasks.
10. Conclusion and publication declarations.

## Decisive scientific distinction

The recorded work supports a functioning prototype composition. It does not yet isolate whether ASH geometry is responsible for the behavioral benefit. A conventional store with the same event matcher remains a serious control, not an alternative that has been ruled out.

The four live paired comparisons concern one task. They are not four independent problem domains. The source records both a successful action change and an inaccurate final explanation. Preserve both in the paper.
